# Characters

## bitty (`bitty-*.svg`)

bitty is the Bitcoin puppet from **Here Comes Bitcoin** by Spiral
(<https://www.herecomesbitcoin.org/>). The site states the assets are
"No Copyright — Make Whatever You Want" and "license-free creative assets
that you can use to make whatever you want". The files are the official
SVGs, unchanged except for an added `viewBox` on two of them so they scale:

| File | Official asset | Used when |
|---|---|---|
| `bitty-happy.svg` | `grumpy.svg` | caught up with the chain (he is always grumpy) |
| `bitty-determined.svg` | `buffbitty.svg` | syncing |
| `bitty-worried.svg` | `hungry.svg` | sync looks stuck / not enough Utreexo peers |
| `bitty-sleeping.svg` | `Cozy-little-guy.svg` | node unreachable (the UI adds "Zzz") |

To use other poses, download them from the Here Comes Bitcoin site and
replace these files (keep the names).

## The forest girl

hair clip and a green hoodie. She has no name yet.
